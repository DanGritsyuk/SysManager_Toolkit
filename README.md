# 🌐 SysManager Toolkit — универсальный системный менеджер

**SysManager Toolkit** — это портативный набор Windows-скриптов, объединённых в единую оболочку для удобного управления SSH-подключениями, сетевой диагностикой, системными утилитами и чтением огромных логов. Проект представляет собой навигационную систему из `.bat`-файлов с интуитивным текстовым интерфейсом, не требующую установки и работающую «из коробки».

> ✅ Подходит для системных администраторов, DevOps, разработчиков и домашних пользователей.

---

## 🧭 Общая архитектура

Проект построен по модульному принципу:

- **Главное меню** (`start.bat`) — точка входа, позволяет выбрать категорию.
- Каждый сценарий имеет собственное подменю и набор утилит.
- **Выход/Назад во всех меню стандартизирован** — клавиша `0`.
- Все `.bat`-скрипты используют кодировку **UTF-8 без BOM** и переводы строк **CRLF**.
- PowerShell-скрипты (`.ps1`) сохраняются в **UTF-8 с BOM** (требование Windows PowerShell 5.1).
- Модули независимы, легко добавлять новые.

## 🚀 Возможности

### 1. SSH-подключения (`connections`)
- Хранит список подключений в `connections/connections.txt` (формат: `Имя,Логин,Хост,Порт`).
- Динамически строит меню на основе содержимого файла (поддерживает любое количество серверов).
- Устойчив к пробелам в именах и файлам с кодировкой UTF-8.
- Выход обратно в главное меню осуществляется по клавише `0`.

### 2. Сетевые сценарии (`network`)
- **Проверка интернета** (`internet_watch`):
  - Пингует внешний хост (по умолчанию `8.8.8.8`).
  - При неудаче проверяет роутер и выполняет сброс сетевых настроек (`ipconfig /release`, `/flushdns`, `/renew`).
  - Ведёт подробный лог и позволяет менять хосты через меню.
- **Управление ARP** (`arp`):
  - Сканирование подсети с автоопределением или ручным вводом (CIDR).
  - Сохранение таблиц с меткой времени в папку `tables/`.
  - Очистка ARP-кэша (требует прав администратора).

### 3. Системные утилиты (`system`)
- **Информация о системе** (`sysinfo`):
  - Сбор данных об ОС, процессоре, памяти и дисках через CIM-классы PowerShell (не зависит от языка ОС).
  - Показывает статус лицензии Windows и ключ (OEM из BIOS, Retail из реестра или generic для digital license).
  - Отчёты сохраняются в `reports/` и **никогда не перезаписываются** (новый файл при каждом запуске).
- **Очистка мусора** (`temp_cleanup`):
  - Режим анализа (Dry-run) по умолчанию — удаление только после подтверждения.
  - Возрастной фильтр (по умолчанию 7 дней) — не трогает файлы, используемые сейчас.
  - Пропускает занятые файлы, ведёт CSV-лог в `logs/`.
  - Поддерживает очистку `Prefetch`, кэшей браузеров и Component Store (DISM).
- **Чтение логов** (`log_reader`):
  - Специализированный инструмент для огромных файлов (ГБ), которые не загружаются в память целиком.
  - **Head** — чтение первых N строк.
  - **Tail** — чтение последних N строк (мгновенно, даже для 10 ГБ файлов).
  - **Live** — режим реального времени (аналог `tail -f` в Linux) для слежения за обновлениями.
  - **Search** — поиск по ключевым словам с контекстом (строками до и после).
  - **Page** — постраничный просмотр всего файла (аналог `more`).
  - Поддерживает перетаскивание файла мышью прямо в окно скрипта.

## ⚙️ Установка и запуск

1. **Скачайте** или склонируйте репозиторий в любую папку.
2. Убедитесь, что в системе установлен **OpenSSH Client** (для работы SSH-модуля) — обычно присутствует в Windows 10/11.
3. Запустите **`start.bat`** двойным щелчком или из командной строки.
4. Используйте цифровые клавиши для навигации. Клавиша **`0`** — выход/назад во всех меню.

> 💡 Для корректной работы ARP-очистки, `Windows Temp`, `Prefetch` и DISM запускайте `start.bat` **от имени администратора**. Остальные модули работают и без прав админа.

## 📝 Настройка

### SSH-подключения
Отредактируйте `connections/connections.txt` в формате: `Имя_сервера,Логин,IP_адрес,Порт`

**Пример:**
```text
MyServer,root,192.168.1.100,22
Production,admin,10.0.0.5,2222
```

### Чтение логов
- Не требует настройки.
- Вы можете перетащить файл прямо в окно `log_reader/start.bat`, либо указать путь вручную (кавычки не обязательны).
- Если лог пишется в кодировке Windows-1251, а не UTF-8, и вы видите кракозябры в содержимом, в файле `log_reader.ps1` замените `-Encoding UTF8` на `-Encoding Default`.

## 🛠 Технические детали

- **Скрипты**: `.bat` для меню и навигации, `.ps1` для сложной логики (вызываются через `powershell -NoProfile -ExecutionPolicy Bypass`).
- **Кодировки**:
  - `.bat` — **UTF-8 без BOM** + `chcp 65001`, переводы строк **CRLF**.
  - `.ps1` — **UTF-8 с BOM** (требование Windows PowerShell 5.1, иначе ломается кириллица).
- **Именование функций в PowerShell** — только approved verbs (`Get-`, `ConvertFrom-`, `Format-` и т.п.), чтобы не сыпались предупреждения `PSScriptAnalyzer`.
- **Требования**: Windows 7 и выше, PowerShell, OpenSSH Client (для SSH).
- **Портативность**: все настройки и артефакты (`reports/`, `logs/`, `tables/`) хранятся в папках рядом со скриптами и добавлены в `.gitignore`.
