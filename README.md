# 🌐 SysManager Toolkit — универсальный системный менеджер

**SysManager Toolkit** — это портативный набор Windows-скриптов, объединённых в единую оболочку для удобного управления SSH-подключениями, сетевой диагностикой и системными утилитами. Проект представляет собой навигационную систему из `.bat`-файлов с интуитивным текстовым интерфейсом, не требующую установки и работающую «из коробки».

> ✅ Подходит для системных администраторов, DevOps, разработчиков и домашних пользователей.

---

## 🧭 Общая архитектура

Проект построен по модульному принципу:

- **Главное меню** (`start.bat`) — точка входа, позволяет выбрать категорию:
  - SSH-подключения
  - Сетевые сценарии
  - Системные утилиты
- Каждый сценарий имеет собственное подменю и набор утилит.
- Все `.bat`-скрипты используют кодировку UTF-8 (`chcp 65001`) для корректного отображения кириллицы.
- PowerShell-скрипты (`.ps1`) сохраняются **в UTF-8 с BOM** — Windows PowerShell 5.1 иначе читает их как ANSI и ломает кириллицу.
- Модули независимы, легко добавлять новые.

## 🚀 Возможности

### 1. SSH-подключения
- Хранит список подключений в файле `connections/connections.txt` (формат: `Имя,Логин,Хост,Порт`).
- Динамически строит меню на основе содержимого файла.
- Запускает `ssh` с указанными параметрами через стандартный клиент OpenSSH (должен быть установлен в системе).

### 2. Проверка интернета (`internet_watch`)
- Проверяет доступность внешнего хоста (по умолчанию `8.8.8.8`).
- В случае отсутствия интернета проверяет доступность роутера.
- Если роутер недоступен — выполняет сброс сетевых настроек (`ipconfig /release`, `/flushdns`, `/renew`).
- Ведёт подробный лог в папке `logs/` (настраивается через `config.ini`).
- Позволяет изменять хосты для проверки через встроенный редактор настроек.

### 3. Управление ARP-таблицей (`arp`)
- **Сканирование сети** — определяет IP-адреса в указанной подсети (или автоопределяет), параллельно пингует их, заполняя ARP-кэш, и выводит полную таблицу.
- **Сохранение результатов** — таблица сохраняется в папку `tables/` с меткой времени (например, `ARP_table_2026-07-30_14-30-45.txt`).
- **Очистка ARP-кэша** — удаляет все записи ARP (требует прав администратора).
- **Быстрый доступ** — пункт меню для открытия папки с сохранёнными таблицами.

### 4. Системная информация (`sysinfo`)
- Собирает сведения об ОС, процессоре, памяти, дисках и сетевых адаптерах через CIM-классы PowerShell (`Win32_ComputerSystem`, `Win32_OperatingSystem`, `Win32_Processor`, `Win32_LogicalDisk`, `Get-NetIPAddress`).
- **Не зависит от языка системы** — в отличие от парсинга вывода `systeminfo` или `wmic`, который ломается на неанглийских локализациях Windows.
- Показывает статус лицензии Windows и ключ, если он хранится на машине:
  - **OEM** — читается из BIOS/UEFI (`OA3xOriginalProductKey`);
  - **Retail/Volume** — из реестра (`BackupProductKeyDefault`) или через декодирование `DigitalProductId`;
  - **Digital license** — реального ключа нет, отображается generic-ключ (это нормально).
- **Сохранение отчётов** — каждый отчёт пишется отдельным файлом в `reports/` с именем `sysinfo_YYYYMMDD_HHMMSS.txt`. Существующие отчёты **никогда не перезаписываются и не удаляются**; при коллизии имени добавляется суффикс `_1`, `_2` и т.д.
- **Ключ не попадает в отчёт** — просматривается только в консоли, чтобы отчёт можно было безопасно прикладывать к тикетам.
- **Fallback** — если PowerShell недоступен (редкий случай), скрипт откатывается на `systeminfo`.

### 5. Очистка временных файлов (`temp_cleanup`)
- **Dry-run по умолчанию** — сначала показывает, сколько файлов и мегабайт будет удалено, и только по явному подтверждению (`YES`) удаляет.
- **Возрастной фильтр** (`-AgeDays`, по умолчанию 7) — не трогает свежие временные файлы, которые могут использоваться запущенными приложениями и установщиками.
- **Пропуск занятых файлов** — файлы, которые не удалось удалить, помечаются `Skipped (in use)` и не считаются ошибкой.
- **CSV-лог каждого запуска** — файл `logs/cleanup_YYYYMMDD_HHMMSS.csv` со списком файлов, размером, возрастом и статусом (`Deleted` / `Skipped` / `Error`). Удобно прикладывать к тикету и сравнивать прогоны.
- **Цели очистки** — `%TEMP%`, `%WinDir%\Temp`, `%LOCALAPPDATA%\CrashDumps`. Опционально: `Prefetch` и кэши Chrome/Edge/Firefox (включаются флагом, не по умолчанию).
- **DISM Component Store** — отдельный пункт меню; `/ResetBase` спрашивается явно, потому что после него откат обновлений Windows становится невозможен.
- **Не выходит за пределы фиксированных целей** — никаких `Remove-Item C:\Windows\*`; системные каталоги (`System32`, `WinSxS`, `Program Files`) в список не попадают.
- **Проверка прав администратора** — без админа `Windows Temp` и `Prefetch` недоступны для записи; скрипт предупреждает об этом заранее.

## ⚙️ Установка и запуск

1. **Скачайте** или склонируйте репозиторий в любую папку.
2. Убедитесь, что в системе установлен **OpenSSH Client** (для работы SSH-модуля) — обычно присутствует в Windows 10/11.
3. Запустите **`start.bat`** двойным щелчком или из командной строки.
4. Используйте цифровые клавиши для навигации по меню.

> 💡 Для корректной работы ARP-очистки, `Windows Temp`, `Prefetch` и DISM запускайте `start.bat` **от имени администратора**. Модули `sysinfo` и `temp_cleanup` работают и без админа, но с ограниченным набором целей.

## 📝 Настройка

### SSH-подключения
Отредактируйте `connections/connections.txt` в формате: `Имя_сервера,Логин,IP_адрес,Порт`

**Пример:**
```text
MyServer,root,192.168.1.100,22
Production,admin,10.0.0.5,2222
```

### Проверка интернета
- Настройки хранятся в `network/internet_watch/config.ini`:
```ini
LOGFILE=network/internet_watch/logs/internet.log
INTERNET_CHECK_HOST=8.8.8.8
ROUTER_HOST=192.168.1.1
```

## Изменение параметров

Изменить параметры можно через меню модуля (пункт 3).

## ARP‑модуль

- Не требует настройки.
- Папка `tables` создаётся автоматически.

При сканировании можно:
- вручную указать подсеть (например, `192.168.1`);
- указать CIDR (например, `192.168.1.0/24`);
- нажать `Enter` для автоопределения.

## Sysinfo

- Не требует настройки.
- Папка `reports` создаётся автоматически при первом сохранении отчёта.
- Отчёты именуются по метке времени и **не перезаписываются**; при совпадении имени добавляется суффикс.
- Ключ Windows показывается только в консоли, в отчёт не пишется.

## Temp Cleanup

- Не требует настройки.
- Папка `logs` создаётся автоматически при первом запуске очистки.
- Возрастной фильтр по умолчанию — 7 дней; можно указать свой при запуске.
- Для `Windows Temp`, `Prefetch` и DISM нужны права администратора.
- В автоматическом режиме (Планировщик задач) сначала неделю погоняйте `-DryRun` и смотрите CSV-логи, чтобы убедиться, что под удаление не попадает ничего нужного:
  ```bat
  powershell -NoProfile -ExecutionPolicy Bypass -File "temp_cleanup.ps1" -Clean -AgeDays 14 -IncludePrefetch
  ```

## 🛠 Технические детали

- **Скрипты**: `.bat`-файлы для меню и навигации, `.ps1` — для сбора данных и логики очистки (вызываются из `.bat` через `powershell -NoProfile -ExecutionPolicy Bypass -File`).
- **Кодировка**:
  - `.bat` — UTF-8 **без BOM** + `chcp 65001`;
  - `.ps1` — UTF-8 **с BOM** (требование Windows PowerShell 5.1).
- **Именование функций в PowerShell** — только approved verbs (`Get-`, `ConvertFrom-`, `Format-` и т.п.), чтобы не сыпались предупреждения `PSScriptAnalyzer(PSUseApprovedVerbs)`.
- **Требования**:
  - Windows 7 и выше;
  - PowerShell (встроен);
  - OpenSSH Client (для SSH).
- **Портативность**: не требует установки; все настройки и артефакты (`reports/`, `logs/`, `tables/`) хранятся в папках рядом со скриптами.
- **Артефакты запуска не попадают в git** — `system/sysinfo/reports/` и `system/temp_cleanup/logs/` добавлены в `.gitignore`.
