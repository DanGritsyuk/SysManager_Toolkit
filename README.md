# 🌐 Универсальный системный менеджер: `SysManager Toolkit`

**SysManager Toolkit** — это портативный набор Windows-скриптов, объединённых в единую оболочку для удобного управления SSH-подключениями и сетевой диагностикой. Проект представляет собой навигационную систему из `.bat`-файлов с интуитивным текстовым интерфейсом, не требующую установки и работающий «из коробки».

> ✅ Подходит для системных администраторов, DevOps, разработчиков и домашних пользователей.
