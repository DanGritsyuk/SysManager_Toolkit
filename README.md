# 🌐 SysManager Toolkit — универсальный системный менеджер

**SysManager Toolkit** — это портативный набор Windows-скриптов, объединённых в единую оболочку для удобного управления SSH-подключениями, сетевой диагностикой, системными утилитами и чтением огромных логов. Проект представляет собой навигационную систему из `.bat`-файлов с интуитивным текстовым интерфейсом, не требующую установки и работающую «из коробки».

> ✅ Подходит для системных администраторов, DevOps, разработчиков и домашних пользователей.

---

## 🧭 Общая архитектура

Проект построен по модульному принципу:

- **Главное меню** (`start.bat`) — точка входа. В шапке показывается контекст: `[ADMIN]`/`[USER]`, имя компьютера, домен и пользователь.
- Каждый сценарий имеет собственное подменю и набор утилит.
- **Выход/Назад во всех меню стандартизирован** — клавиша `0`.
- **CWD всегда = папка скрипта.** `start.bat` и все подменю начинаются с `cd /d "%~dp0"`/`cd /d "%~dp0.."`, а внутренние вызовы используют `%~dp0`. Это гарантирует работу как при двойном клике, так и при **запуске от имени администратора** (UAC-элевация создаёт новую консоль с CWD `C:\Windows\System32`).
- Все `.bat`-скрипты используют кодировку **UTF-8 без BOM** и переводы строк **CRLF**.
- PowerShell-скрипты (`.ps1`) сохраняются в **UTF-8 с BOM** (требование Windows PowerShell 5.1, иначе кириллица ломается и парсер падает с `Unexpected token` / `TerminatorExpectedAtEndOfString`).
- Модули независимы, легко добавлять новые.

## 🚀 Возможности

### 0. Главное меню (`start.bat`)
- **Контекст в шапке**: `[ADMIN]`/`[USER]`, `%COMPUTERNAME%`, `%USERDOMAIN%\%USERNAME%` — защита от «не на той машине».
- **Doctor** — быстрая проверка окружения (PS-версия, ExecutionPolicy, права, OpenSSH, UTF-8, наличие конфигов).
- **Поиск команды** — список всех доступных сценариев по ключевому слову.
- Работает одинаково **с правами пользователя и администратора**: подменю и внутренние вызовы используют `%~dp0`.

### 1. SSH-подключения (`connections`)
- Хранит список подключений в `connections/connections.txt` (формат: `Имя,Логин,Хост,Порт`).
- Динамически строит меню на основе содержимого файла, **без лимита в 9 серверов** — поддерживает любое количество.
- Устойчив к пробелам в именах и файлам с кодировкой UTF-8.
- Выход обратно в главное меню — клавиша `0`.

### 2. Сетевые сценарии (`network`)
- **Проверка интернета** (`internet_watch`):
  - Пингует внешний хост (по умолчанию `ya.ru`), при неудаче — роутер.
  - При недоступности обоих выполняет `ipconfig /release`, `/flushdns`, `/renew`.
  - Ведёт подробный UTF-8-лог и позволяет менять хосты через меню.
- **Управление ARP** (`arp`):
  - Сканирование подсети с автоопределением или ручным вводом (CIDR, три октета).
  - Сохранение таблиц с меткой времени в `tables/`.
  - Очистка ARP-кэша — с подтверждением и проверкой прав администратора.
- **Порты и процессы** (`port_owner`):
  - Список всех слушающих портов (`LocalAddress:Port → PID → Process`).
  - Поиск процесса по номеру порта (кто занял `443`).
  - Поиск портов по имени процесса (частичное совпадение).

### 3. Системные утилиты (`system`)
- **Информация о системе** (`sysinfo`):
  - ОС, CPU, RAM, диски, сетевые адаптеры, uptime — через CIM-классы (не зависит от языка ОС).
  - Статус лицензии Windows + ключи (OEM из BIOS, Retail из реестра, DigitalProductId).
  - Отчёты сохраняются в `reports/` и **никогда не перезаписываются**.
- **Проверка дисков** (`disk_check`):
  - Физические диски, состояние здоровья, износ, температура, часы работы.
  - Логические диски с предупреждением «мало места» (`< 15%`).
  - SMART-предсказание отказа (через WMI).
- **Очистка мусора** (`temp_cleanup`):
  - **Dry-run по умолчанию** — удаление только после явного `YES`.
  - Возрастной фильтр (по умолчанию 7 дней) — не трогает свежие и используемые файлы.
  - Пропускает занятые файлы, пишет CSV-лог в `logs/`.
  - Prefetch, кэши Chrome/Edge/Firefox, Component Store (`DISM /ResetBase` с отдельным подтверждением).
- **Чтение логов** (`log_reader`):
  - **Head** — первые N строк.
  - **Tail** — последние N строк (мгновенно даже для 10 ГБ).
  - **Live** — режим `tail -f`.
  - **Search** — поиск с контекстом (до/после).
  - **Page** — постранично (аналог `more`).
  - **Смена кодировки из меню** — пункт «Сменить кодировку» (`UTF8` / `Default` / `Windows-1251`), без ручного редактирования `.ps1`.
  - Поддержка drag-and-drop файла в окно.
- **Управление службами** (`service_manager`):
  - Список служб с фильтром по имени/отображаемому имени.
  - Перезапуск с **понятными сообщениями об ошибках** («Нет прав…», «Служба не найдена…», «Защищена…») вместо сырых `ServiceCommandException`.
  - Просмотр зависимостей: «зависит от» и «от неё зависят».
  - Список служб с автозапуском.
- **Топ по размеру** (`disk_top`):
  - Топ-20 файлов в `C:\` (или указанном пути).
  - Топ-20 папок по суммарному размеру.
- **Сбор диагностики** (`collect`):
  - Один zip с `systeminfo`, `ipconfig /all`, `route`, `arp`, портами, службами, топ-50 процессов, дисками, последними 100 записями System и Application журналов.
  - Удобно прикладывать к тикету.

## ⚙️ Установка и запуск

1. **Скачайте** или склонируйте репозиторий в любую папку.
2. Убедитесь, что установлен **OpenSSH Client** (для SSH-модуля) — обычно есть в Windows 10/11.
3. Запустите **`start.bat`** двойным щелчком или из командной строки.
4. Навигация — цифровыми клавишами. Клавиша **`0`** — выход/назад во всех меню.

> 💡 **Права администратора** нужны для: очистки ARP, `Windows Temp`, `Prefetch`, `DISM`, управления большинством служб. Остальные модули работают и без прав. При запуске от администратора окно консоли может отличаться по шрифту/размеру — это поведение UAC (новый `conhost.exe`). Один раз настройте свойства окна (Правый клик → Свойства → «Применить ко всем окнам с этим именем»), чтобы вид стал одинаковым.

> 💡 **CWD не «уезжает»**: `start.bat` и подменю используют `%~dp0` и `cd /d`, поэтому работают независимо от того, откуда запущены — двойным кликом, из ярлыка «от имени администратора» или из другого каталога.

## 📝 Настройка

### SSH-подключения
Отредактируйте `connections/connections.txt`:

```text
MyServer,root,192.168.1.100,22
Production,admin,10.0.0.5,2222
```

### Проверка интернета
Файл `network/internet_watch/config.ini`:

```ini
[Settings]
LOGFILE=network\internet_watch\log\internet_check.log
INTERNET_CHECK_HOST=ya.ru
ROUTER_HOST=192.168.1.1
```

Меняется из меню «Проверка Интернета» → пункт `3 - Изменить настройки`.

### Чтение логов
- Не требует настройки. Файл можно перетащить мышью прямо в окно `log_reader/start.bat`.
- **Кодировка переключается из меню** — пункт «Сменить кодировку» (`UTF8` / `Default` / `Windows-1251`). Редактировать `.ps1` не нужно.

## 🛠 Технические детали

- **Скрипты**: `.bat` — меню и навигация, `.ps1` — логика (вызываются через `powershell -NoProfile -ExecutionPolicy Bypass -File ...`).
- **Кодировки**:
  - `.bat` — **UTF-8 без BOM**, `chcp 65001`, переводы строк **CRLF**.
  - `.ps1` — **UTF-8 с BOM** (обязательно, иначе Windows PowerShell 5.1 читает кириллицу как CP1251 → кракозябры и синтаксические ошибки парсера).
- **Именование функций PowerShell** — approved verbs (`Get-`, `ConvertFrom-`, `Format-`, `Test-` и т.п.), `PSScriptAnalyzer`-совместимо.
- **Обработка ошибок** — `$ErrorActionPreference = 'Stop'` в скриптах с `try/catch`, дружелюбные сообщения об ошибках (`Get-FriendlyError` в `service_manager.ps1`).
- **Требования**: Windows 7 и выше, Windows PowerShell 5.1, OpenSSH Client (для SSH).
- **Портативность**: все артефакты (`reports/`, `logs/`, `tables/`, `connections.txt`) хранятся рядом со скриптами и добавлены в `.gitignore`.

### Массовое исправление кодировки (если клонировали и `.ps1` без BOM)

```powershell
$root = "<путь к SysManager_Toolkit>"
Get-ChildItem -Path $root -Recurse -Filter *.ps1 | ForEach-Object {
    $bytes = [System.IO.File]::ReadAllBytes($_.FullName)
    $hasBom = $bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF
    if (-not $hasBom) {
        $bom = [byte[]](0xEF, 0xBB, 0xBF)
        [System.IO.File]::WriteAllBytes($_.FullName, $bom + $bytes)
        Write-Host "BOM added: $($_.FullName)"
    }
}
```

Проверка: `Format-Hex -Path <файл> -Count 3` → первые байты должны быть `EF BB BF`.

## 🤝 Вклад в развитие

Проект открыт для доработок. Что можно добавить:

- **Сеть**: `port.test`/скан портов, DNS-диагностика (разные серверы), traceroute/MTU-проба, управление firewall, Wi-Fi профили.
- **SSH**: управление ключами, `ssh-copy-id`, редактор `~/.ssh/config`, batch-выполнение по инвентарю хостов.
- **Система**: pending reboot, аудит автозапуска, BitLocker, установленные обновления, инвентарь софта, поиск дубликатов.
- **Интерфейс**: переход на `Spectre.Console` (таблицы, прогресс-бары, live-панели), единый `-Json` на каждом модуле для интеграции со скриптами и CI.

Каждый новый модуль — это пара `.bat` + `.ps1` в своей папке и одна строка `call "%~dp0имя\start.bat"` в соответствующем меню.
